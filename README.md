# PromptHub · 精选 AI 提示词库

> 让 ChatGPT / Claude / DeepSeek 输出质量提升 10 倍

**🌐 在线访问：** https://yuanweibi-bot.github.io/prompt-hub/

## ✨ 特点

- **中英双语** — 每个提示词提供中文和 English 两个版本
- **精选来源** — 来自 GitHub 143k+ stars 社区 + 中文万人库
- **六大分类** — 写作、编程、商业、学习、创意、高阶
- **社区驱动** — 用户可在线投稿，支持双向语言
- **一键复制** — 点击即可复制提示词到剪贴板
- **完全免费** — 开源、无广告、社区维护

## 📂 分类

| 分类 | 说明 |
|------|------|
| 📝 写作 | 学术论文、简历优化、小红书文案、英文邮件、SEO 文章 |
| 💻 编程 | 代码调试、SQL 优化、单元测试、API 设计、数据库设计 |
| 💼 商业 | 商业计划书、产品卖点、竞品分析、营销文案 |
| 📚 学习 | 读书笔记、学习计划、知识卡片 |
| 🎨 创意 | 短视频脚本、品牌命名、故事创作、角色扮演 |
| 🚀 高阶 | 思维链、角色组合技、逆向工程、双语生成 |

## 🚀 本地运行

```bash
# 克隆
git clone https://github.com/yuanweibi-bot/prompt-hub.git
cd prompt-hub

# 直接用浏览器打开 index.html 即可
# 或启动本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```
